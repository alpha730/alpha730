# Setup: manual steps for you

Steps 1 and 2 are done: `alpha730/alpha730` exists, and the workflow has run once. The rest only you can do.

## 1. Create the repo and push (done)
For reference only:
```sh
git remote add origin https://github.com/alpha730/alpha730.git
git push -u origin main
```
`node_modules/` and `preview/` are git-ignored.

## 2. Enable the live-stats workflow (done)
1. Repo **Settings > Actions > General > Workflow permissions**: choose **Read and write permissions**.
2. **Actions** tab > "Update profile stats" > **Run workflow**.
3. It then runs daily and commits only files under `assets/` with the message `chore: refresh profile stats [skip ci]`.

**After pushing the ink theme, run the workflow once by hand.** The live panels (streak, languages, activity) show "AWAITING THE FIRST RAVEN" until it does. The workflow saves the numbers it fetches in `assets/live-data.json`, so later theme rebuilds (`npm run build`) re-render the live panels without losing the data.

**Limitations**
- **The live stats count public contributions only.** The built-in `GITHUB_TOKEN` can't see your private contributions. A personal access token could, but I deliberately didn't use one, so no secrets are stored.
- The longest streak and the contribution total cover the **last 12 months** (the window the contributions API returns), not your all-time record.
- GitHub pauses scheduled workflows after 60 days without repo activity. Check the Actions tab if the stats stop updating, and re-enable the workflow if needed.
- The SVGs follow your **operating system or browser** light/dark setting, not GitHub's own theme switcher.
- The workflow uses `actions/checkout@v5` and `actions/setup-node@v5`, both verified to exist and to run on Node 24. Newer majors (v7) exist if you want to move up later.

## 3. Pin repos on your profile (GitHub UI only)
On your profile, choose **Customize your pins** and select:
`Prompt-injection-Tester-`, `sih-project`, `ASHA-Voice-Logging-Agent`, `DUO-Game`.
**Remove the DRISHTI pin**, which belongs to another account.

## 4. Optional renames
`Aryan---cv` and `Prompt-injection-Tester-` could have cleaner names. If you rename `Prompt-injection-Tester-`, update `repo` in `profile.config.json`, then run `npm run build` and commit. GitHub redirects the old URL, but fix the links anyway. `README.md` is generated by the build, so its links update too.

## 5. Fill the missing metric (The Raven's Eye, `sih-project`)
The `sih-project` chapter shows no metric on purpose, because no measured number exists yet. When you have a real one:
1. Set `result` on mission 2 in `profile.config.json` to a short sentence, as the other missions do.
2. Run `npm run build`. The README is regenerated, and the `<!-- TODO: add metric -->` comment disappears with it.

## 6. Check The Raven's Eye stack wording
I derived the `sih-project` chapter's stack from the repo itself (`pyproject.toml` and README). The chapter lists **Python, PyTorch, LangGraph, Rasterio** and "SAR + optical". The repo doesn't use LangChain, GDAL or RAG, and it never mentions multispectral. Edit `profile.config.json` if you want different wording.

## Rebuilding locally
```sh
npm install        # only needed for the PNG preview (resvg)
npm run build      # regenerate every SVG in assets/ and README.md from profile.config.json
npm run render     # PNG previews in preview/ (desktop + 330px, dark + light, hero filmstrip)
npm run validate   # README/asset/scope checks
```
The ASCII art is generated procedurally from fixed seeds, so the same config always produces the same SVGs.

Live-stat data comes from `node scripts/live-stats.mjs`. It needs a `GITHUB_TOKEN` in your environment, which the workflow supplies, and it refuses to run without one.
